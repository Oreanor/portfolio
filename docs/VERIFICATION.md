# Проверка первой реализации — 16 ноября 2026

## Выполнено

- `npm run build`: успешно, Next.js 16.4.6; 33 статические страницы проектов, по 3 каталога и About.
- `npm run lint`: успешно, без предупреждений.
- `npm run typecheck`: успешно.
- `npm test`: 3 проверки успешно — состав 11/3/2/6, полнота переводов и контента, выбор языка браузера.
- `npm run test:smoke`: успешно — все 33 проекта, 3 каталога, 3 About, выбор языка/сохранённая cookie, совместимость старых URL, query-параметры, неизвестные страницы с HTTP 404, 3 OG-картинки, robots и sitemap.
- Браузер: EN, RU и PT-PT проверены на 360, 390, 768, 1024 и 1440 px. Во всех 15 вариантах `scrollWidth` равен ширине видимой области, горизонтального скролла нет.
- Фильтры в браузере: All = 11, Tools = 3, Data = 2, Games = 6; Enter активирует ссылку; Back и Forward восстанавливают категорию.
- Переключение PT → EN сохраняет `?category=games#work` и шесть видимых игр.
- Страница City Rider: переход из каталога и смена EN → RU сохраняют проект, русский текст и блок игрового процесса присутствуют, мобильная вёрстка не переполняется.
- Консоль проверенной вкладки: сообщений уровня error нет.
- Известные внешние ссылки: профиль GitHub, Kludge Code, Genealogy, HWDB и Star Elite ответили HTTP 200. Работа каждого демо целиком не проверялась.

## Ограничения проверки

Дополнительно после правки интерфейса: язык выбирается нативным селектом EN/RU/PT. В браузере проверены сохранение категории и обновление языка документа при смене EN → RU, ширина 360 px, затухание/появление сетки, быстрые переключения фильтров и Back. Сборка, lint, типы и unit-проверки прошли; ошибок консоли нет.

- Реальные изображения, видео, CV, email и LinkedIn ещё не предоставлены. Медиа-ветки галереи предусмотрены, но не проверены на будущих авторских файлах.
- Lighthouse не запускался; оценки производительности и доступности не заявляются.
- Полная ручная проверка каждого текста на каждом устройстве не выполнялась. Маршруты и наличие индивидуального контента проверены автоматически, адаптивность — на главных страницах и выбранной странице игры.
- `SITE_URL` пока не задан. Sitemap остаётся пустым, canonical/hreflang не генерируются; Next.js предупреждает о локальном адресе изображений Open Graph. Перед публикацией нужен реальный домен и повторная сборка.
- Режим `globalNotFound` отмечается Next.js как experimental; он используется для общей 404 при корневом сегменте языка в соответствии с документацией установленной версии.
