# Что нужно от автора

Описания всех 11 проектов уже подготовлены на английском, русском и европейском португальском. Писать их заново не требуется: достаточно поправить факты, статус или акценты при просмотре.

## Обязательное для наполнения

1. **Скриншоты**: желательно 2–4 настоящих кадра каждого проекта, WebP или PNG, ширина 1440–1920 px. Для обложки удобен горизонтальный кадр около 16:10; галерея принимает любые пропорции. Не добавлять секреты, адреса электронной почты игроков и частные данные семьи.
2. **Контакты**: публичный email и точная ссылка LinkedIn. Сейчас доступен подтверждённый GitHub; отсутствующие контакты не изображены кнопками.
3. **Реальное резюме PDF**: для кнопки CV и проверки названий работодателей/дат. Пока профиль описывает отрасли без неподтверждённой хронологии.
4. **Ссылки**: точные demo/repository/download URL там, где они ещё не даны. Необязательно публиковать исходники каждого проекта — можно оставить только демо или описание.
5. **Домен**: нужен перед публикацией для `SITE_URL`, canonical, hreflang, sitemap и абсолютных ссылок OG.

## Необязательно, но полезно

- 10–25-секундный ролик для портала/масштаба Star Elite, налёта Skladron, разговора Maeth и поездки City Rider. MP4 с отдельным постером, без автозапуска на сайте.
- Статус каждого продукта: используется, активно развивается или оставлен как прототип. Сейчас статусы описывают только документированные способы доступа и ограничения.
- Портрет для About, если хочется его показывать. Сейчас дизайн обходится без фотографии.
- Уточнения личного вклада, если формулировки на странице проекта нужно сделать точнее. Работа с AI описана открыто, без утверждений о ручном написании всего кода.

## Что учтено при сверке

- Lesson Player: локальный перевод не означает гарантированно автономное распознавание речи. Web Speech зависит от Chrome и его реализации.
- Star Elite: клиентская сетевая симуляция не называется отдельным авторитетным сервером.
- Maeth: правила из актуального перевода учитывают лучников и одно действие за партию.
- Two Towers: локальная игра, без сетевых матчей и аккаунтов.
- City Rider: объяснены реальные занятия игрока; интернет для карт и доработка плавности на разных GPU обозначены.
- Middle-earth: явно неофициальный фанатский проект; чужая графика не копировалась.
