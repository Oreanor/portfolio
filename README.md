# Sergei Nikonets — портфолио

Next.js App Router, React, TypeScript и Tailwind CSS. Первая локальная версия на основе `docs/CODEX_PORTFOLIO_SPEC_RU.md`, правил и визуальных референсов. **11 равноправных проектов**: по дополнительной инструкции автора добавлен City Rider. Категории: 3 инструмента, 2 проекта данных, 6 игр.

## Запуск

```powershell
npm ci
npm run dev
```

Открыть `http://127.0.0.1:3000`. Если порт занят: `npm run dev -- --port 3002`.

```powershell
npm run build
npm run start -- --port 3002
```

Не запускать dev и production build одновременно: они используют одну папку `.next`. При ограничениях Windows-песочницы Turbopack может не суметь запустить дочерний процесс CSS; сборку нужно запускать в обычном терминале с доступом к локальным процессам.

## Языки и маршруты

- `/en`, `/ru`, `/pt`: каталог, по 11 проектов, и раздел «Опыт и подход» на той же странице.
- `/{locale}/projects/{slug}`: 33 статические страницы проектов.
- `/` выбирает наиболее приоритетный поддерживаемый язык из `Accept-Language`, иначе английский. Ручной выбор сохраняется на год в функциональной cookie `portfolio-language` и имеет приоритет.
- Переключатель сохраняет страницу, query-параметры и якорь. Старые адреса `/projects/{slug}` и `/about` перенаправляются на языковой маршрут; `/about` ведёт к якорю опыта.
- Навигация «Проекты» и «Опыт и подход» использует якорные ссылки `/#work` и `/#about`.
- Категория сохраняется в `?category=tools|data|games`; Back/Forward восстанавливают фильтр. Без JavaScript доступны тексты всех проектов и обычные ссылки.

## Контент

- `src/content/projects.ts`: общая модель, английские тексты, стек, реальные ссылки и медиа.
- `src/content/project-translations.ts`: полные русские и португальские тексты (PT-PT).
- `src/content/gameplay.ts`: понятное описание игрового процесса шести игр на трёх языках.
- `src/lib/i18n.ts`: переводы интерфейса и выбор языка.
- `src/content/profile.ts`: публичные контакты, CV и адрес production-сайта.

Тексты сверены с локальными README исходных проектов. Игровой процесс дополнительно описан по правилам City Rider (`RulesDialog.tsx`), Maeth и Two Towers (переводы `rules.body`), Skladron (`lib/i18n/rules.ts`), гайду Middle-earth и README/переводам контрактов Star Elite. Конфиденциальные настройки и `.env` исходных проектов не читались и не копировались.

## Добавление скриншотов

Положить файлы в `public/projects/{slug}/`. Добавить запись в `media` соответствующего проекта:

```ts
media: [
  {
    type: "image",
    src: "/projects/city-rider/city.webp",
    width: 1600,
    height: 1000,
    alt: "A drive through a generated city in City Rider",
    caption: "Roads and buildings generated from vector map data.",
  },
  {
    type: "video",
    src: "/projects/city-rider/drive.mp4",
    poster: "/projects/city-rider/drive-poster.webp",
    caption: "A short drive through the city.",
  },
]
```

Первое изображение становится обложкой карточки; галерея показывает все медиа. Полный кадр открывается по клику, видео — нативным плеером без автозапуска. `alt` и подписи можно переопределить в локализованных данных при добавлении медиа. Сейчас все заглушки явно обозначены и не имитируют интерфейсы приложений.

## SEO перед публикацией

Задать `SITE_URL` в окружении хостинга или терминала сборки, например своим реальным доменом. После этого пересобрать сайт: canonical, hreflang, structured data и sitemap используют именно его. Без домена sitemap намеренно пуст, canonical не публикуются, Next.js предупреждает о локальном адресе OG-картинок. Это ожидаемая настройка локального предпросмотра.

Метаданные страниц, JSON-LD Person/CreativeWork, robots, иконка и OG-изображение на каждом языке уже реализованы. `globalNotFound` включён для корректной общей 404 при корневом динамическом сегменте языка.

## Проверки

```powershell
npm run lint
npm run typecheck
npm test
npm run build
# После запуска production-сервера на 3002:
npm run test:smoke
```

Для другого адреса проверки задать переменную `SMOKE_URL`. Smoke-проверка читает 33 страницы проектов, 3 главные с разделами проектов и опыта, проверяет 404, редиректы, cookie языка, OG-изображения и SEO-маршруты. Unit-проверки контролируют полноту переводов, состав категорий, уникальность контента и обработку языка браузера.
